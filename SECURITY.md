# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | ✅ |
| < 1.0 | ❌ |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub: on the repository page, open
**Security → Report a vulnerability**. Include the affected version, steps to
reproduce, and the impact you observed. You should get an acknowledgement
within a few days.

## Security model

How StreamSage protects Kafka access, credentials, HTTP access and message
data is described in [docs/security.md](docs/security.md).
